# 0.2.0 原生迁移验证记录

验证日期：2026-10-21。本机 Windows 10.0.26300.0、MSVC 19.44、x64 Release、静态 MSVC 运行库。此记录不是 Windows 10 22H2 / Windows 11 干净系统验收结果。

## 已运行

- CTest 四组通过：59 项真实媒体检查、21 项界面检查、23 项安装检查，以及真实原生 COM Shell 接口检查。两类 Shell 和单实例管道分别验证了 4,000 文件交接。
- 媒体覆盖严格字节上限、完整/编辑后时长、图片方向/透明度、HDR 确认、软件回退、音频转换、轨道选择、换封装、剪辑/组合滤镜/变速、文本字幕、拼接和预览。新增非方形像素保持显示比例、慢速样片最长 10 秒、预览保留较小输出尺寸检查。
- 界面覆盖双语、参数快照、异步探测、Media Foundation 定位/播放/暂停、资源释放、小窗口滚动和键盘焦点可见性。截图位于 artifacts/native-ui-tests。
- 安装检查覆盖校验值、非法 ZIP、个人文件保护、升级失败回滚、文件占用预检查和只删除清单文件；未修改系统注册。
- 原生发行检查直接读取安装器 PE 资源：两个安装器的配置校验值与便携 ZIP 一致；完整安装器嵌入 ZIP 的实际字节 SHA-256 一致；小安装器没有引擎载荷。
- 已从便携目录执行 --check-engine，确认实际使用随包的 ffmpeg/ffprobe，返回值均为 0。
- dumpbin 检查主程序、安装器、Shell DLL：无 CLR、MSVCP 或 VCRUNTIME 动态依赖。已移除 C# 工程及 .NET 发布步骤。

管道和带可选包身份的应用激活受到开发沙箱限制，相关检查在沙箱外运行；测试没有安装身份包、信任证书或注册菜单。

## 体积与运行观测

- 主程序约 910 KiB；主程序、基础安装/卸载器和 Shell DLL 合计约 1.62 MiB。
- 固定 FFmpeg / ffprobe 两个引擎文件合计约 370.3 MiB；压缩后整个便携包约 145 MiB。引擎构建保持不变。
- 英文 UI 测试进程：窗口构建约 172 ms；空队列私有内存约 2.66 MiB、工作集约 16.54 MiB；播放测试片段时私有内存约 82.7 MiB、工作集约 89.4 MiB。

内存值来自独立的原生 UI 测试进程，包含测试代码；启动值只测窗口构建，不含系统进程加载。播放片段为 128×96 H.264、两秒、无音轨。数值为一次本机观测，不代表冷启动或大分辨率视频的性能保证。原始值见 artifacts/native-ui-tests/metrics-en.json。
